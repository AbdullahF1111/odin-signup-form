# Sign-up Form

## 📝 Description
This project is a responsive Sign-up Form built as part of a web development curriculum. The goal of this project is to apply concepts of building HTML forms, input validation, and utilizing CSS Flexbox and CSS Grid to create a precise, flexible layout that matches the provided design.

## 🚀 Built With
* Semantic HTML5
* CSS3 (Flexbox & CSS Grid)
* Responsive Design (Media Queries)
* Custom Local Fonts integration via `@font-face`
* CSS Pseudo-classes (for focus states and custom input validation styling)

## 💡 What I Learned
While building this project, I strengthened my skills in:
1. Building a two-column layout using `Flexbox` and controlling its behavior on smaller viewports.
2. Using `CSS Grid` to elegantly and evenly organize form inputs.
3. Importing and utilizing custom local fonts (like the *Norse* font) within a project.
4. Completely shifting the layout on mobile screens to make the sidebar appear at the top using the `order` property in Flexbox.
